Tax Rules Engine — Global
Two-layer evaluation — Jurisdiction Claims decide where, Tax Treatments decide how much
Jurisdiction Claims 0
Tax Treatments 0
Base Definitions 0
Simulator
Layer 1 · "Where". A Claim states that a jurisdiction has a taxing right over an award. Claims are evaluated before any Treatment fires, and each admitted claim causes the Treatment layer to run exactly once — so every Treatment evaluation sees exactly one jurisdiction. Sub-national claims nest inside a country claim but may use a different sourcing method and their own admitted share.
Layer 2 · "How much". One Treatment wins per claim, and it declares taxability explicitly as withhold, report only, or not taxable here. A single Treatment may emit several components — each with its own base, tax type, flavour and payer — which is what covers multi-component cases like a qualifying ESPP disposition without duplicating rules.
Bases are data, not code. Each definition is a small serialized expression over a fixed operand set with + − × and max/min — enough to express every equity base without a general-purpose language. This is the construct that turns "add a new taxable event" from an engine change into a data change.
